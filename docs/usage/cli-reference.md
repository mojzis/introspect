## `introspy cache-ttl`

```
Usage: introspy cache-ttl [OPTIONS]

  Would a 1h or 5m prompt-cache TTL have been cheaper?

  Replays every API request under both policies. The prefix a request re-sends
  is the same either way; only the read/write split moves, so the comparison
  turns on one thing — which gaps each TTL would have kept warm.

Options:
  --verify     Show the simulation's parity residuals and 5m/1h split coverage
               instead of the recommendation.
  --subagents  Score sidechain traffic (subagentPromptCacheTtl) instead of the
               main conversation. Never merged with the main-chain verdict.
  --help       Show this message and exit.
```

## `introspy claude`

```
Usage: introspy claude [OPTIONS]

  Launch Claude Code connected to the introspect MCP server.

  Starts `introspy serve` automatically in the background when nothing is
  listening on the target port (log at `~/.introspect/serve.log`) and stops it
  again when Claude Code exits (pass `--keep-server` to leave it up). A server
  that was already running is never touched.  The MCP config is passed inline,
  so nothing is written to your Claude Code settings — the server is only
  registered for this session.

  Any extra arguments are forwarded to the `claude` CLI as-is, e.g. `introspy
  claude -- --model opus --resume` or `introspy claude -- -p "recent sessions"`.
  Use `--` to separate introspect's own options from the ones meant for Claude
  Code.

Options:
  --port INTEGER  Port the introspect server is listening on  [default: 8347]
  --host TEXT     Host the introspect server is bound to  [default: 127.0.0.1]
  --keep-server   Leave the auto-started server running after Claude Code exits
  --help          Show this message and exit.
```

## `introspy devserve`

```
Usage: introspy devserve [OPTIONS]

  Launch the web UI with auto-reload on source changes.

  Uses a per-branch DuckDB (`introspect-<branch>.duckdb`) so dev servers on
  different branches never share a schema-mismatched database. Respects an
  explicit `INTROSPECT_DB_PATH` if set. Also prunes dev DBs for branches that no
  longer exist.

Options:
  --port INTEGER         Port to listen on  [default: 8347]
  --host TEXT            Host to bind to  [default: 127.0.0.1]
  -d, --days INTEGER     Days of history to load (0 = no limit)  [default: 10]
  --no-resolve-projects  Skip git worktree resolution for project names
  --clean                Rebuild this branch's dev DB from scratch instead of
                         reusing it
  --help                 Show this message and exit.
```
