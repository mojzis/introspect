{# Shared Prev/Next + page-size pager. ``url`` is a caller-supplied macro taking ``(page, page_size)`` and returning the href for that combination — every page builds its query string differently (filters, sort, tab), but the control itself is the same everywhere. Callers that have no size choice pass ``page_sizes=[]``. #} {% macro pager(url, page, total_pages, page_size, page_sizes) %}
{% if page > 1 %} Prev {% endif %} Page {{ page }} of {{ total_pages }} {% if page < total_pages %} Next {% endif %} {% if page_sizes %} Show {% for ps in page_sizes %} {% if ps == page_size %} {{ ps }} {% else %} {{ ps }} {% endif %} {% if not loop.last %}/{% endif %} {% endfor %} per page {% endif %}
{% endmacro %}
